# Plan: markets and logistics data

Status: agreed 2026-11-07, first version built. The data lives in
`docs/markets/`. The views are generated by `scripts/markets.py`.

## Why

The logistics and product-compliance research (`research-logistics.md`,
`research-product-compliance.md`, `research/`) is prose. To pick
countries and carriers we need the same facts as tables: one place per
fact, with where it came from and how sure we are, and a clear mark where
a value waits on a re-fetch, an email or an adviser.

## Decisions

- **CSV files in the repo are the source of truth** (decided 2026-11-07:
  only the logistics lead and Claude edit for now, and git history shows
  how each fact changed). The `.xlsx` for Google Drive and the HTML page
  are generated from them and never edited by hand. The `.xlsx` has one
  sheet per CSV with the same columns, so edits made in Drive can later be
  read back into the CSVs. That import is not built yet; it is built when
  someone first edits in Drive.
- **One row per fact, not per country** (decided 2026-11-07: sources and
  certainty differ per fact). The wide country overview is generated.
- **All ISO 3166-1 countries are listed** with a market status; only the
  researched ones (about 45) have facts. More are researched as merchants'
  buyers call for them.
- **Facts can be set for a group** (EU, ASEAN, GCC) and overridden per
  country. The most specific row wins. Two groups giving the same fact for
  one country is an error.
- **Origin is a column** (decided 2026-11-07: only VN for now, other SEA
  origins later). Facts that depend on it (FTA preference) and every
  carrier service carry it.
- **A fixed list of product categories** in `categories.csv`: apparel,
  leather footwear, ceramics, keycaps, lacquerware, wooden goods. A fact
  with no category applies to all. Adding a category is one row.
- **Carrier prices are split** into services, rate cards, zones, rates and
  surcharges, because each changes on its own (fuel monthly, rate cards
  yearly, zones rarely). Each rate card keeps its own weight breaks and
  its own currency (VN cards are in VND). Amounts are integers in the
  currency's minor unit, as in AGENTS.md Money and Ledger.
- **The files live in `docs/markets/`, not `data/`** (decided 2026-11-07:
  `data/` is gitignored for real merchant and buyer data; this is public
  research and belongs with the other research documents).
- **Sources are inline** on each row (`source`, `source_url`,
  `research_ref`), not in a separate table, so a hand edit needs no
  lookup.
- **Provider documents go in `docs/markets/sources/<provider>/`**, named
  after the provider id (decided 2026-11-07: one place per provider for
  rate guides, zone charts and quote emails). The documents are
  gitignored because carrier rate files are often for registered
  customers only; each folder's committed `README.md` lists the files and
  where to get them.
- **Open work is in `questions.csv`**: emails to carriers, adviser
  questions and re-fetches. A fact waiting on one has status
  `awaiting_answer` and the question id.

## Status values

| Status | Meaning |
|---|---|
| `verified` | read in a primary source (authority, gazette, carrier rate card) |
| `secondary` | adviser, law firm, carrier marketing, press or aggregator |
| `estimate` | our inference, a rating, a conversion or a third-party estimate |
| `unverified` | a value we have but could not confirm, or sources conflict |
| `to_fetch` | no value yet; can be looked up on the web |
| `awaiting_answer` | no reliable value; waits on the linked question |
| `n/a` | does not apply |

## Files

| File | One row per |
|---|---|
| `countries.csv` | ISO 3166-1 country: codes, name, UN region, currency, market status |
| `groups.csv` | group (EU, ASEAN, GCC, research regions) and its members |
| `categories.csv` | product category |
| `topics.csv` | fact topic: what a column of the overview means |
| `facts.csv` | fact: country or group × topic × category × origin |
| `questions.csv` | open question: email, adviser question or re-fetch |
| `providers.csv` | logistics or landed-cost provider and our contact status |
| `services.csv` | carrier service from an origin |
| `rate_cards.csv` | price list of a service: kind, currency, validity |
| `zones.csv` | country or group → zone, per rate card |
| `rates.csv` | price per rate card × zone × weight |
| `surcharges.csv` | fee per service |
| `transit.csv` | transit days per service × destination |
| `service_restrictions.csv` | what a service allows per product category |

## Commands

```
uv run scripts/markets.py check   # validate all CSVs
uv run scripts/markets.py build   # check, then write the views
```

`build` writes `docs/markets.html` and `docs/markets/out/markets.xlsx`
(not committed; upload it to Drive).

## Project rules applied

- Money and Ledger: amounts as integer minor units with the currency; no
  floats. Rates converted to USD only for display, with the rate shown.
- Merchant of Record Domain Rules: tax rules per jurisdiction with dates
  and sources, so a later module can be seeded from them; compliance and
  licensing points are flagged, not assumed.
- Record Decisions Inline: decisions above carry their date and reason.
