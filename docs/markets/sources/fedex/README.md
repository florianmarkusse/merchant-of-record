# FedEx (VN origin)

Rate files need a FedEx account registered for Tariff Pricing
(https://www.fedex.com/en-vn/shipping/rates/customized-rates/export.html).

| File | What | Status |
|---|---|---|
| `fedex-rates-exp-en-vn-2026.pdf` | 2026 export tariff: IP, IPE, IE (from 2026-01-05) | wanted |
| `fedex-rates-cm-en-vn-2026.pdf` | zone index for the export tariff | wanted |
| `fedex-rates-ficp-exp-en-vn-2026.pdf` | 2026 FICP export tariff | wanted |
| `fedex-rates-ficp-cm-en-vn-2026.pdf` | FICP zone index | wanted |
| `fedex-rates-g3pie-en-vn-2026.pdf` | IE, Global Third-Party (VN export billed to a non-VN account) | wanted |
| `fedex-apac-service-guide-en-vn.pdf` | APAC service guide | wanted |
| `fedex-ds-2026-*-638-en-vn.pdf` | demand surcharge notices | wanted |

Today's FedEx rows in the CSVs are `unverified` (read from search
extracts); question q29.
